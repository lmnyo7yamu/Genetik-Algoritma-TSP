# Genetic Algorithm - TSP (Part 1)

This project is the first step of solving the Traveling Salesperson Problem. 

## Features
* Reads city coordinates from a `.tsp` file.
* Calculates the distance between cities.
* Creates a random, valid travel route.

## How to run
Put `main.py` and `berlin11_modified.tsp` in the same folder and run `python main.py` in your terminal.
